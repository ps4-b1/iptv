# IPTV Web Player v2

واجهة IPTV كاملة من الصفر، بدون مكتبات خارجية، ومناسبة للكمبيوتر ومتصفح PS4.

## الملفات
- `index.html` — الواجهة.
- `styles.css` — التصميم المتجاوب.
- `app.js` — تشغيل M3U/M3U8 وXtream، البحث، التصنيفات، المفضلة، واختبار الإنترنت.

## اختبار الإنترنت
عند فتح الصفحة يظهر في أعلى الواجهة:
- "الإنترنت يعمل بنجاح" باللون الأخضر عند نجاح الاتصال.
- زمن الوصول بالـ ms.
- حالة أسفل الصفحة.

الفحص يستخدم طلب HTTPS إلى Google `generate_204` بوضع `no-cors`. هذا يؤكد قدرة المتصفح على الوصول إلى الإنترنت، لكنه لا يثبت أن كل خوادم IPTV متاحة.

## GitHub Pages
1. أنشئ Repository جديداً.
2. ارفع الملفات الثلاثة إلى الفرع `main`.
3. Settings -> Pages -> Deploy from a branch -> `main` -> `/root`.
4. افتح رابط GitHub Pages على الكمبيوتر أو PS4.

## M3U / Xtream و CORS
المتصفح لا يستطيع تجاوز CORS. لذلك:
- ملف M3U يجب أن يسمح بطلبات المتصفح.
- Xtream API يجب أن يسمح بطلبات المتصفح.
- رابط البث نفسه يجب أن يكون صالحاً للمتصفح/PS4.
GitHub Pages بحد ذاته لا يعمل كـ proxy ولا يتجاوز CORS.

## ملاحظة PS4
هذه الواجهة لا تعتمد على مكتبات JavaScript خارجية، لتقليل مشاكل التوافق. تشغيل HLS/M3U8 يعتمد على دعم صيغة البث في متصفح PS4 وإعدادات خادم IPTV.
